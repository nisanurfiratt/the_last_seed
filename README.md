# The Last Seed

A small interactive ecosystem experiment for NMED 3203 / Interactive Media Applications.

## Premises
- **Agency:** the participant's actions directly change the seed's resources, stress and growth.
- **Possibility:** the current ecosystem state determines which actions are available.

## How to use
Open `index.html` in a modern browser. Choose actions in the right-hand panel and observe how the ecosystem changes. Disabled actions explain what condition is needed to unlock them. When the plant blooms, its flower colour reflects the dominant environmental resource or elevated stress. The event log also reports the numerical effects of each action. Use **Restart experiment** to try a different path.

## Files
- `index.html` — page structure and interface.
- `style.css` — visual design and responsive layout.
- `script.js` — state, rules, feedback and action availability. Changeable parameters are grouped in `SETTINGS` at the top.
